**Источник правды — сами репозитории**: их документы и настройки линтеров главнее этого навыка. Навык говорит, где их искать и что из них важнее всего; полные правила читай на месте.

## Общий порядок

1. Перед правкой прочитай правила репозитория (таблица ниже) и два-три соседних файла того же рода. Пиши так же: имена, структура, обработка ошибок, язык комментариев.
2. Настройки линтеров и форматирования не меняй и новых исключений не добавляй — чини код.
3. Сгенерированное руками не правь: меняется источник, результат пересобирается генератором.
4. Меняешь поведение API — обнови описание контракта в том же репозитории, если оно там ведётся.
